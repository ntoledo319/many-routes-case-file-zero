# Case File Zero: The Elm Street Cash Drawer

A **free** 10–15 minute solo deduction mini-case. Two pages, five people, six documents, one statement that can't be true. Print it or read it on screen.

**[Download the PDF (US Letter)](case-file-zero.pdf)** · [Play in the browser](https://ntoledo319.github.io/many-routes-case-file-zero/)

- Page 1: the setup, the people and six evidence documents
- Page 2: an accusation box, then the answer printed upside down, with every step cited to a document

The logic is machine-checked: `node check.mjs` confirms that exactly one key-holder could have opened the drawer and that exactly one statement is contradicted by the evidence.
