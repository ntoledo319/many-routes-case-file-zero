League Gothic (The League of Moveable Type; Google Fonts release)
  LeagueGothic-Regular.ttf = static instance (wdth 100) of LeagueGothic[wdth].ttf

Libre Caslon Text (Impallari Type; Google Fonts release)
  LibreCaslonText-Regular.ttf / -Bold.ttf = static instances (wght 400 / 700) of LibreCaslonText[wght].ttf
  LibreCaslonText-Italic.ttf = static instance (wght 400) of LibreCaslonText-Italic[wght].ttf,
  with the historical s_t / s_p ligatures removed from the default 'liga' feature.

Instances made with fontTools varLib.instancer. Neither licence declares a Reserved
Font Name, so the modified instances keep their original names under the OFL.
